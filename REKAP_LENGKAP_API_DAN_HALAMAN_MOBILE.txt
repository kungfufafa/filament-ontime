1. INFORMASI DASAR API & INFORMASI KONFIGURASI KONEKSI
================================================================================
- Base URL Server:
  * Android Emulator: http://10.0.2.2:8000/api/v1
  * iOS Simulator / Web: http://127.0.0.1:8000/api/v1
  * HP Fisik (Wi-Fi): http://<IP-Lokal-Komputer>:8000/api/v1 (contoh: http://192.168.1.15:8000/api/v1)

- Header Wajib Request API:
  * Authorization: Bearer <access_token_sanctum>
  * Accept: application/json
  * Content-Type: application/json (atau multipart/form-data untuk upload foto/file)

- Format Respons Standard API:
  * Sukses: { "data": [...], "pagination": {...}, "message": "Pesan sukses" }
  * Error: { "message": "Pesan deskripsi kesalahan" } (HTTP Status 401/422/403/404/409)

2. SPESIFIKASI LENGKAP ENDPOINT REST API V1 (54 ROUTES)
================================================================================

[A] AUTENTIKASI (/auth)
1. POST /api/v1/auth/login
   - Request Body: { "email": "string", "password": "string" }
   - Response 200: { "message": "Login successful", "token": "1|...", "token_type": "Bearer", "user": { ... } }
2. GET /api/v1/auth/me
   - Header: Authorization Bearer
   - Response 200: { "user": { "id": 1, "name": "...", "email": "...", "roles": ["..."], "permissions": ["..."], "employee": {...}, "intern": {...}, "freelancer": {...} } }
3. POST /api/v1/auth/logout
   - Header: Authorization Bearer
   - Response 200: { "message": "Logged out successfully" }

[B] PRESENSI ABSENSI (/attendance)
1. POST /api/v1/attendance/check-in
   - Form-Data Body: latitude (float), longitude (float), photo (file image selfie)
   - Response 200: { "message": "Check in berhasil", "attendance": { ... } }
2. POST /api/v1/attendance/check-out
   - Form-Data Body: latitude (float), longitude (float), photo (file image selfie)
   - Response 200: { "message": "Check out berhasil", "attendance": { ... } }
3. GET /api/v1/attendances
   - Query Params: start_date, end_date, month, year, status
   - Response 200: { "data": [ { "id": 1, "date": "...", "check_in": "...", "check_out": "...", "status": "...", "is_out_of_bounds": bool, "late_minutes": int } ], "pagination": {...} }
4. POST /api/v1/attendance/master-face
   - Form-Data Body: photo (file image biometrik master)
   - Response 200: { "message": "Foto Master Wajah berhasil diperbarui", "data": { "master_face_photo": "url", "master_face_verified_at": "datetime" } }
5. GET /api/v1/attendances/{id}
   - Response 200: { "data": { ... detail presensi lengkap ... } }

[C] PENGAJUAN CUTI & IZIN (/leave-requests)
1. GET /api/v1/leave-requests
   - Response 200: { "quota_summary": { "annual_leave_quota": int, "used_days": int, "remaining_days": int }, "data": [ { "id": 1, "leave_type": "annual/sick/permission", "start_date": "...", "end_date": "...", "days_count": int, "reason": "...", "status": "pending/approved/rejected", "attachment": "url" } ], "pagination": {...} }
2. POST /api/v1/leave-requests
   - Form-Data Body: leave_type (string), start_date (date YYYY-MM-DD), end_date (date YYYY-MM-DD), reason (text), attachment (file opsional)
   - Response 201: { "message": "Pengajuan cuti berhasil dibuat", "data": { ... } }
3. PUT /api/v1/leave-requests/{id}
   - Form-Data Body: leave_type, start_date, end_date, reason, attachment (Hanya jika status pending)
   - Response 200: { "message": "Pengajuan cuti berhasil diperbarui", "data": { ... } }
4. GET /api/v1/leave-requests/{id}
   - Response 200: { "data": { ... detail pengajuan cuti ... } }

[D] PENGAJUAN LEMBUR (/overtime-requests)
1. GET /api/v1/overtime-requests
   - Response 200: { "data": [ { "id": 1, "date": "...", "start_time": "...", "end_time": "...", "duration_minutes": int, "reason": "...", "status": "pending/approved/rejected" } ], "pagination": {...} }
2. POST /api/v1/overtime-requests
   - Request Body: { "date": "YYYY-MM-DD", "start_time": "HH:MM", "end_time": "HH:MM", "reason": "text" }
   - Response 201: { "message": "Pengajuan lembur berhasil dibuat", "data": { ... } }
3. PUT /api/v1/overtime-requests/{id}
   - Request Body: { "date", "start_time", "end_time", "reason" } (Hanya jika status pending)
   - Response 200: { "message": "Pengajuan lembur berhasil diperbarui", "data": { ... } }
4. GET /api/v1/overtime-requests/{id}
   - Response 200: { "data": { ... detail pengajuan lembur ... } }

[E] PENGAJUAN KOREKSI ABSENSI (/attendance-corrections)
1. GET /api/v1/attendance-corrections
   - Response 200: { "data": [ { "id": 1, "date": "...", "corrected_check_in": "...", "corrected_check_out": "...", "reason": "...", "status": "pending/approved/rejected", "attachment": "url" } ], "pagination": {...} }
2. POST /api/v1/attendance-corrections
   - Form-Data Body: date (YYYY-MM-DD), corrected_check_in (HH:MM:SS), corrected_check_out (HH:MM:SS), reason (text), attachment (file opsional)
   - Response 201: { "message": "Pengajuan koreksi absensi berhasil dibuat", "data": { ... } }
3. PUT /api/v1/attendance-corrections/{id}
   - Form-Data Body: date, corrected_check_in, corrected_check_out, reason, attachment
   - Response 200: { "message": "Pengajuan koreksi absensi berhasil diperbarui", "data": { ... } }
4. GET /api/v1/attendance-corrections/{id}
   - Response 200: { "data": { ... detail koreksi absensi ... } }

[F] PENGAJUAN RESIGN / PENGUNDURAN DIRI (/resignations)
1. GET /api/v1/resignations
   - Response 200: { "data": [ { "id": 1, "resignation_date": "...", "last_working_day": "...", "reason": "...", "handover_notes": "...", "status": "pending/approved/rejected" } ] }
2. POST /api/v1/resignations
   - Request Body: { "resignation_date": "YYYY-MM-DD", "last_working_day": "YYYY-MM-DD", "reason": "text", "handover_notes": "text" }
   - Response 201: { "message": "Pengajuan pengunduran diri berhasil dibuat", "data": { ... } }
3. GET /api/v1/resignations/{id}
   - Response 200: { "data": { ... detail pengunduran diri ... } }

[G] INBOX PERSETUJUAN ATASAN (/approvals)
1. GET /api/v1/approvals/pending
   - Response 200: { "leave_requests": [...], "overtime_requests": [...], "attendance_corrections": [...], "geofence_attendances": [...], "resignations": [...] }
2. PUT /api/v1/approvals/{type}/{id}/process
   - Path Params: type = leave/overtime/correction/geofence/resignation, id = ID data
   - Request Body: { "action": "approved" / "rejected", "rejection_note": "text opsional jika rejected" }
   - Response 200: { "message": "Pengajuan berhasil disetujui/ditolak", "status": "approved/rejected", "current_step": int }

[H] KALENDER CUTI & LAPORAN (/kalender-cuti, /laporan-absensi)
1. GET /api/v1/kalender-cuti?month=MM&year=YYYY&company_id=ID
   - Response 200: { "data": [ { "id": 1, "employee_name": "...", "leave_type": "...", "start_date": "...", "end_date": "...", "status": "approved" } ] }
2. GET /api/v1/laporan-absensi?start_date=YYYY-MM-DD&end_date=YYYY-MM-DD
   - Response 200: { "summary": { "total_present": int, "total_late": int, "total_leave": int, "total_absent": int }, "data": [...] }

[I] MASTER DATA & SHIELD INSPECTION (/master, /shield)
- GET /api/v1/shield/roles ➔ Daftar seluruh Role sistem
- GET /api/v1/shield/permissions ➔ Daftar seluruh Permission sistem
- GET & GET /{id} untuk: /master/companies, /master/company-locations, /master/company-policies, /master/divisions, /master/job-titles, /master/job-levels, /master/employees, /master/interns, /master/freelancers, /master/holidays, /master/approval-flows, /master/approvers, /master/users.

3. MATRIKS HAK AKSES TAMPILAN BERDASARKAN PERAN (ROLE-BASED DISPLAY RULES)
================================================================================

A. ROLE: INTERN (PESERTA MAGANG)
   - TAMPILKAN (MUST SHOW):
     * Badge Role "Peserta Magang".
     * Presensi Mandiri (Check-In & Check-Out dengan Kamera Selfie + GPS Geofence).
     * Foto Master Wajah Biometrik (Status Terdaftar & Tombol Kamera Master).
     * Kartu Informasi Mentor: Nama Mentor Karyawan (user.intern.mentor.full_name), Instansi Sekolah/Kampus (user.intern.institution), Perusahaan, Divisi.
     * Menu Pengajuan Koreksi Absensi (Jika lupa tap in/out).
     * Laporan Presensi Diri.
   - SEMBUNYIKAN (MUST HIDE):
     * ❌ Kuota Cuti & Form Pengajuan Cuti (Magang tidak punya kuota cuti tahunan).
     * ❌ Form Pengajuan Lembur.
     * ❌ Form Pengajuan Resign / Pengunduran Diri.
     * ❌ Tab Inbox Persetujuan Atasan.
     * ❌ Kalender Cuti Tim.

B. ROLE: FREELANCER (PEKERJA LEPAS)
   - TAMPILKAN (MUST SHOW):
     * Badge Role "Pekerja Lepas".
     * Presensi Mandiri (Check-In & Check-Out Kamera Selfie + GPS Geofence).
     * Foto Master Wajah Biometrik (Status Terdaftar & Tombol Kamera Master).
     * Kartu Informasi Supervisor: Nama Supervisor Karyawan (user.freelancer.supervisor.full_name), Nama Proyek/Instansi (user.freelancer.institution), Perusahaan, Divisi.
     * Menu Pengajuan Koreksi Absensi.
     * Laporan Presensi Diri.
   - SEMBUNYIKAN (MUST HIDE):
     * ❌ Kuota Cuti & Form Pengajuan Cuti.
     * ❌ Form Pengajuan Lembur.
     * ❌ Form Pengajuan Resign.
     * ❌ Tab Inbox Persetujuan Atasan.
     * ❌ Kalender Cuti Tim.

C. ROLE: EMPLOYEE (KARYAWAN TETAP / KONTRAK)
   - TAMPILKAN (MUST SHOW):
     * Badge Role "Karyawan".
     * Presensi Mandiri (Check-In & Check-Out Kamera Selfie + GPS Geofence).
     * Foto Master Wajah Biometrik.
     * Kartu Kuota Cuti Tahunan (Sisa Kuota, Terpakai, Maksimal Kuota Kebijakan Perusahaan).
     * Form & Riwayat Pengajuan Cuti & Izin.
     * Form & Riwayat Pengajuan Lembur.
     * Form & Riwayat Pengajuan Koreksi Absensi.
     * Form & Status Pengajuan Resign / Pengunduran Diri.
     * Kalender Cuti Tim se-Perusahaan.
     * Laporan Presensi Diri.
   - SEMBUNYIKAN (MUST HIDE):
     * ❌ Tab Inbox Persetujuan Atasan (Kecuali jika ditugaskan sebagai Approver/BOD).

D. ROLE: APPROVER / BOD / SUPERADMIN (ATASAN & DIREKSI)
   - TAMPILKAN (MUST SHOW):
     * Seluruh Fitur Karyawan (Presensi, Cuti, Lembur, Koreksi, Resign, Kalender Cuti, Laporan Diri).
     * 📥 Tab Inbox Persetujuan Atasan (Approval Saya):
       - Antrean Persetujuan Cuti Bawahan.
       - Antrean Persetujuan Lembur Bawahan.
       - Antrean Persetujuan Koreksi Absensi Bawahan.
       - Antrean Persetujuan Absensi Luar Geofence (Dilengkapi peta komparasi GPS Karyawan vs Kantor).
       - Antrean Persetujuan Resign Bawahan.
     * Counter Badge Jumlah Antrean Approval Pending di Dashboard.
     * Modal Keputusan: Tombol Setujui (Approve) & Tombol Tolak (Reject) + Catatan Alasan Penolakan.

4. RINCIAN HALAMAN APLIKASI MOBILE EXPO (PAGE-BY-PAGE BREAKDOWN)
================================================================================

1. HALAMAN LOGIN (app/login.tsx)
   - Endpoint API: POST /api/v1/auth/login
   - Komponen UI:
     * Header Logo & Judul Aplikasi "Filament OnTime Mobile".
     * Input Text: Email & Password.
     * Tombol Aksi: "Masuk Sekarang".
     * Alert Banner error jika kredensial salah / tidak cocok.
   - Flow Logika:
     * Sukses login ➔ Simpan Token Sanctum ke Storage local ➔ Simpan User & Roles ke AuthContext ➔ Redirect ke Dashboard Utama (`/(app)`).

2. HALAMAN DASHBOARD UTAMA (app/(app)/index.tsx)
   - Endpoint API: GET /api/v1/auth/me, GET /api/v1/attendances, GET /api/v1/approvals/pending
   - Komponen & Pemetaan Data:
     * Header Card: Nama User (user.name), Email, Badge Role (user.roles[0]), Nama Perusahaan (user.employee.company.name / user.intern.company.name / user.freelancer.company.name), Nama Divisi.
     * Status Presensi Hari Ini: Jam Check-In, Jam Check-Out, Status (Tepat Waktu / Terlambat / Menunggu Persetujuan).
     * Status Foto Master Biometrik: Indikator Terdaftar / Belum Terdaftar (user.employee.master_face_photo / user.intern.master_face_photo).
     * Card Khusus Intern: Nama Mentor (user.intern.mentor.full_name), Instansi (user.intern.institution).
     * Card Khusus Freelancer: Nama Supervisor (user.freelancer.supervisor.full_name), Proyek/Instansi (user.freelancer.institution).
     * Card Khusus Employee: Kuota Cuti Tahunan (user.employee.company.policy.annual_leave_quota - cuti terpakai).
     * Card Khusus Approver: Widget Counter Inbox Approval Pending.

3. HALAMAN PRESENSI MANDIRI (app/(app)/attendance/index.tsx)
   - Endpoint API: POST /api/v1/attendance/check-in, POST /api/v1/attendance/check-out, GET /api/v1/attendances
   - Komponen & Pemetaan Data:
     * CameraView (expo-camera): Preview Kamera Selfie Depan.
     * Status Lokasi & GPS (expo-location): Latitude, Longitude, Jarak Terdeteksi (Meter) vs Radius Maksimal Kantor (user.company.locations[0].radius_meters).
     * Tombol Aksi: Button "Presensi Masuk" & Button "Presensi Keluar".
     * Logika Submit: Ambil Foto Selfie (takePictureAsync) + Lat/Lng Current ➔ Form-Data ke POST /attendance/check-in ➔ Tampilkan Alert Sukses/Gagal dari respons API.
     * Tabel Riwayat Presensi Pribadi: List 10 presensi terakhir (Tanggal, Check-In, Check-Out, Status, Badge Luar Geofence).

4. HALAMAN FOTO MASTER WAJAH (app/(app)/attendance/master-face.tsx)
   - Endpoint API: GET /api/v1/auth/me, POST Upload Foto Biometrik Master
   - Komponen UI: Preview Foto Master Biometrik saat ini, Pilihan Dual-Mode (Upload Galeri HP / Ambil Kamera Selfie Langsung).

5. HALAMAN PUSAT PENGAJUAN (app/(app)/requests/index.tsx)
   - Endpoint API: GET /api/v1/leave-requests, GET /api/v1/overtime-requests, GET /api/v1/attendance-corrections, GET /api/v1/resignations
   - Komponen UI:
     * Grid Menu Pengajuan: Tombol Cuti, Lembur, Koreksi Absensi, Pengunduran Diri (Di-filter dinamis berdasarkan Role).
     * List Riwayat Pengajuan: Teks Alasan, Tanggal, dan Badge Status (Menunggu / Disetujui / Ditolak).

6. FORM PENGAJUAN CUTI & IZIN (app/(app)/requests/leave.tsx)
   - Endpoint API: POST /api/v1/leave-requests
   - Form Inputs: Jenis Cuti (annual/sick/permission), Tanggal Mulai (start_date), Tanggal Selesai (end_date), Alasan Cuti, Upload Lampiran File (attachment).

7. FORM PENGAJUAN LEMBUR (app/(app)/requests/overtime.tsx)
   - Endpoint API: POST /api/v1/overtime-requests
   - Form Inputs: Tanggal Lembur (date), Jam Mulai (start_time), Jam Selesai (end_time), Alasan Pekerjaan Lembur.

8. FORM KOREKSI ABSENSI (app/(app)/requests/correction.tsx)
   - Endpoint API: POST /api/v1/attendance-corrections
   - Form Inputs: Tanggal Absensi Bermasalah (date), Jam Check-In Disesuaikan, Jam Check-Out Disesuaikan, Alasan Kendala, Upload Lampiran Bukti.

9. FORM PENGUNDURAN DIRI / RESIGN (app/(app)/requests/resignation.tsx)
   - Endpoint API: POST /api/v1/resignations
   - Form Inputs: Tanggal Pengajuan Resign, Tanggal Hari Kerja Terakhir (last_working_day), Alasan Utama Resign, Catatan Serah Terima Pekerjaan (handover_notes).

10. HALAMAN INBOX PERSETUJUAN ATASAN (app/(app)/approvals/index.tsx)
    - Endpoint API: GET /api/v1/approvals/pending, PUT /api/v1/approvals/{type}/{id}/process
    - Komponen UI:
      * Tab Navigasi Kategori: Cuti, Lembur, Koreksi Absensi, Absensi Luar Geofence, Resign.
      * Kartu Pengajuan Bawahan: Nama Bawahan, Divisi, Tanggal, Alasan, File Lampiran.
      * Kartu Khusus Luar Geofence: Peta Komparasi Koordinat Karyawan saat Absen vs Koordinat Kantor Perusahaan.
      * Modal Aksi Decision: Button "Setujui" (Approve) & Button "Tolak" (Reject) + Form Input Alasan Penolakan (rejection_note).

11. HALAMAN KALENDER CUTI TIM (app/(app)/calendar/index.tsx)
    - Endpoint API: GET /api/v1/kalender-cuti?month=MM&year=YYYY&company_id=ID
    - Komponen UI: Grid Kalender Bulanan Tim, Penanda Warna Cuti Rekan Kerja se-Perusahaan.

12. HALAMAN LAPORAN PRESENSI DIRI (app/(app)/reports/index.tsx)
    - Endpoint API: GET /api/v1/laporan-absensi?start_date=YYYY-MM-DD&end_date=YYYY-MM-DD
    - Komponen UI: Card Ringkasan Total Hadir, Total Menit Keterlambatan, Total Cuti, Total Absen.

13. HALAMAN PROFIL PENGGUNA (app/(app)/profile/index.tsx)
    - Endpoint API: GET /api/v1/auth/me, POST /api/v1/auth/logout
    - Komponen UI:
      * Kartu Biodata & Foto Wajah.
      * Detail Badan Usaha, Divisi, Jabatan, NIP/NIS.
      * Data Penanggung Jawab: Nama Mentor (Magang) / Nama Supervisor (Freelancer).
      * Modal Pengaturan Server API Base URL (http://10.0.2.2:8000/api/v1 / IP Wi-Fi Laptop).
      * Tombol Keluar (Logout).
